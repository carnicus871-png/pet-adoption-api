# Pet Adoption Catalogue API

## Description

The Pet Adoption Catalogue API is a Spring Boot REST application that allows users to manage pets available for
adoption. It stores pet information in a MySQL database and provides endpoints to retrieve, add and search for pets.

## Technologies

- Java 25
- Spring Boot 4
- Spring Data JPA
- MySQL
- Lombok
- OpenAPI (Swagger)
- Maven

## Features

- View all pets
- Add a new pet
- Search pets by species
- Store data in MySQL
- Logging with SLF4J
- Configuration using @Value
- Swagger API documentation

## API Endpoints

| Method | Endpoint                 | Description            |
|--------|--------------------------|------------------------|
| GET    | /                        | Welcome message        |
| GET    | /pets                    | Retrieve all pets      |
| POST   | /pets                    | Add a new pet          |
| GET    | /pets/search?species=Dog | Search pets by species |

## Running the Project

1. Clone the repository.
2. Create a MySQL database.
3. Update the database credentials in `application.properties`.
4. Run the Spring Boot application.
5. Open Swagger at:

http://localhost:8080/swagger-ui.html
